OXYGEN GYM - COMPLETE VS CODE + LIVE SERVER PROJECT

RUN:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Install the VS Code extension "Live Server" by Ritwick Dey.
4. Right-click index.html.
5. Click "Open with Live Server".

No XAMPP, PHP, Node.js, or database server is required.

The project contains:
- Home
- Member Registration
- Login
- Member Dashboard
- Attendance
- Membership and Renewal
- Payments
- Admin Dashboard
- Contact form

Everything is inside index.html, so the website works as a single-file project.
Member/demo data is stored in browser LocalStorage.
